# Basic EDA & Preprocessing

This repository contains basic **Exploratory Data Analysis (EDA)** and **Data Preprocessing** steps for preparing datasets before applying Machine Learning models.

## Topics Covered
- Data loading and initial inspection
- Checking data types and missing values
- Handling missing data
- Removing duplicates
- Feature analysis and visualization
- Outlier detection

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Purpose
The main goal of this project is to understand raw data, clean it properly, and transform it into a machine-learning-ready format.

## Workflow
1. Load dataset  
2. Perform basic EDA  
3. Clean and preprocess data
